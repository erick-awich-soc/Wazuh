# Wazuh Labs

## Overview
This repository documents my hands-on labs and practical learning using Wazuh, an open-source security platform used for security monitoring, threat detection, vulnerability detection, and incident response.

The goal is to develop practical Security Operations Center (SOC) skills through host-based monitoring, log analysis, security alert investigation, and threat detection.

## Objectives
- Install and configure Wazuh.
- Deploy and manage Wazuh agents.
- Monitor endpoint security events and system logs.
- Analyze and investigate security alerts.
- Detect file integrity changes.
- Monitor vulnerabilities and security configurations.
- Investigate suspicious activities using Wazuh dashboards.
- Develop practical SOC monitoring and incident investigation skills.

## Tools and Technologies
- **Wazuh** — Security monitoring and threat detection.
- **Linux** — System administration and lab environment.
- **Windows** — Endpoint monitoring and security event collection.
- **Virtual Machines** — Isolated lab environments.
- **Sysmon** — Windows system activity monitoring, where applicable.
